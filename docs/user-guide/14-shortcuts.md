# 14. Keyboard Shortcuts

[← Audio and MIDI Devices](13-devices.md) · [Contents](README.md)

On Windows and Linux, use **Ctrl** for **Cmd** and **Alt** for **Option**.

## Transport

| Key | Action |
|---|---|
| Space | Play / stop |
| R | Record / stop recording |
| L | Loop on / off |
| Home | Return to start |

## Files

| Key | Action |
|---|---|
| Cmd+N | New project |
| Cmd+O | Open... |
| Cmd+S | Save |
| Cmd+Shift+S | Save As... |
| Cmd+I | Import MIDI file... |
| Cmd+Shift+I | Import audio file... |
| Cmd+E | Export score as PDF... |
| Cmd+Shift+E | Export audio... |

## Editing

| Key | Action |
|---|---|
| Cmd+Z | Undo |
| Cmd+Shift+Z | Redo |
| Delete / Backspace | Delete the selected clip, or the selected notes in the Piano Roll |
| Cmd+T | Split the selected clip at the playhead (with none selected, every clip the playhead crosses) |
| Cmd+X / Cmd+C | Cut / copy the selected clip |
| Cmd+V | Paste at the playhead, on the track last clicked |
| Cmd+D | Duplicate the selected clip (a copy right after it) |
| Cmd+A | Select all notes (Piano Roll) |

## Arrangement view

| Key | Action |
|---|---|
| Cmd+= (or Cmd++) | Zoom in |
| Cmd+− | Zoom out |
| Cmd+0 | Show the whole song (Fit) |
| Cmd+Shift+F | Score and Piano Roll at full height (hides the arrangement) |

## Mouse

**Arrangement:**

| Gesture | Action |
|---|---|
| Drag a clip | Move it (snaps to bars) |
| Shift-drag a clip | Move it, snapping to beats |
| Option-drag a clip | Copy it |
| Drag a clip's right edge | Change its length |
| Double-click a MIDI clip | Edit its notes |
| Right-click a clip | Clip menu (split, cut, copy, duplicate, ...) |
| Right-click an empty lane | Move the playhead there; Paste, Split All Clips at Playhead |
| Click the ruler's bar numbers, or an empty lane | Move the playhead |
| Drag along the top of the ruler | Set the loop range (Shift snaps to beats) |
| Click the loop band | Loop on / off |
| Pinch, or Cmd+scroll | Zoom |
| Sideways swipe, or Shift+scroll | Scroll through time |

**Automation lane** (right-click the track header > Automation):

| Gesture | Action |
|---|---|
| Click | Add a point |
| Drag a point | Move it (Shift snaps to beats) |
| Double-click a point | Remove it |
| Right-click | Delete Point, Clear Automation, Hide Automation |
| Click the label | Choose another setting |

**Track header:**

| Gesture | Action |
|---|---|
| Double-click the name | Rename |
| Right-click the header | Rename or delete the track |
| Double-click the volume slider | 0 dB |
| Double-click the pan knob | Centre |
| Click a level meter | Clear its over-0 dB light |

**Piano Roll:**

| Gesture | Action |
|---|---|
| Double-click | Add a note |
| Drag a note / its right edge | Move it / change its length |
| Alt while dragging | Ignore the grid |
| Drag on empty space | Select notes (Shift adds) |
| Shift-click a note | Add it to or remove it from the selection |
| Click a key | Hear the pitch |

**Effects panel:**

| Gesture | Action |
|---|---|
| Double-click a knob | Reset it (the reverb send to Off) |
